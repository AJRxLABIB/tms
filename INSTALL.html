Complete Setup Guide

TMS — Tourism Management System

Full installation guide. Follow these steps from zero to a running tourism management website on your local machine or live server.

Overview

What is TMS?

TMS is a complete PHP + MySQL web application for managing a tourism business. It includes a public-facing website for customers to browse and book tour packages, and a full admin panel to manage everything.

🌐
Public Website
Tour packages, booking, reviews, blog, wishlist, AI recommendations, weather guide, maps, loyalty points, and more.
⚙️
Admin Panel
Manage packages, bookings, users, enquiries, revenue analytics, coupon codes, blog posts, reports, activity log.
🗄️
Database
MySQL / MariaDB. All data stored locally. No cloud database required. Import with one click in phpMyAdmin.
🔒
Security
CSRF protection, bcrypt passwords, PDO prepared statements, input sanitization on every form.

Installation

Step-by-Step Setup

1

Download and Install XAMPP

Go to the official XAMPP website and download the installer for your operating system.

https://www.apachefriends.org/download.html
Windows:

Run the .exe installer. When asked for install location, use C:\xampp — do NOT install inside Program Files as this causes permission errors. Keep all default components selected (Apache, MySQL, PHP, phpMyAdmin).

Mac:

Open the .dmg file and drag XAMPP to /Applications. Open it from Applications.

Linux (Ubuntu/Debian):
chmod +x xampp-linux-x64-8.2.x-installer.run
sudo ./xampp-linux-x64-8.2.x-installer.run
2

Start Apache and MySQL

Open the XAMPP Control Panel and click Start next to both Apache and MySQL. Both should turn green.

⚠️ Windows — Port 80 conflict: If Apache won't start, port 80 is taken (by IIS or Skype). In XAMPP Control Panel → Config → Apache (httpd.conf) → find Listen 80 → change to Listen 8080. Then access the site at http://localhost:8080/tms/.
⚠️ Windows — Port 3306 conflict: If MySQL won't start, another MySQL might be running. Stop it from Windows Services (Win+R → services.msc → find MySQL → Stop).
3

Extract and Place the Project Files

Extract the downloaded tms.zip file. You will get a folder named tms. Copy this entire folder into the XAMPP web root:

Windows: C:\xampp\htdocs\tms\
Mac: /Applications/XAMPP/htdocs/tms/
Linux: /opt/lampp/htdocs/tms/
✅ After copying, verify: C:\xampp\htdocs\tms\index.php should exist. If you see tms\tms\index.php you extracted one level too deep — move the inner folder up.
4

Create the Database

Open your browser and go to:

http://localhost/phpmyadmin

Then follow these steps:

  1. Click New in the left sidebar
  2. In "Database name" type: tms
  3. Collation: select utf8_general_ci
  4. Click Create
  5. Click on the new tms database in left sidebar
  6. Click the Import tab at the top
  7. Click Choose File → navigate to your tms folder → database/legacy-sql/ → select tms.sql
  8. Scroll down, click Go — wait for green success message
  9. Click Import again → database/legacy-sql/ → select v6_migration.sql → click Go
✅ After importing both SQL files, click on the tms database — you should see 15+ tables like tblusers, tblbooking, tbltourpackages, etc.
5

Configure Database Connection

Open this file in any text editor (Notepad, VS Code, etc.):

tms/includes/config.php

Find these 4 lines near the top and update them:

define('DB_HOST', 'localhost'); // ← keep as is
define('DB_USER', 'root'); // ← default XAMPP username
define('DB_PASS', ''); // ← empty = no password (XAMPP default)
define('DB_NAME', 'tms'); // ← the database name you created
✅ For standard XAMPP, you don't need to change anything here — the defaults already match.
6

Set Folder Permissions (Linux / Mac only)

These upload folders need write permission. Open Terminal and run:

cd /opt/lampp/htdocs/tms/
chmod 777 uploads/
chmod 777 uploads/reviews/
chmod 777 admin/pacakgeimages/
mkdir -p admin/blogimages && chmod 777 admin/blogimages/
ℹ️ Windows users skip this step — XAMPP on Windows handles permissions automatically.
7

Open the Website

With Apache and MySQL running in XAMPP, open your browser and visit:

http://localhost/tms/
← Public website
http://localhost/tms/admin/
← Admin panel
✅ The homepage should show the TMS website with tour packages. The admin panel should show a login page.
8

Log In to Admin Panel

Go to http://localhost/tms/admin/ and sign in.

Default credentials (from database/legacy-sql/tms.sql):
Username: admin
Password: Test@12345
⚠️ Change the admin password immediately after first login. Go to Admin Panel → Change Password.
ℹ️ If you're not sure of the password, open phpMyAdmin → tms database → tbladmin table → edit the row and set a new bcrypt hash, or run: UPDATE tbladmin SET AdminPassword = MD5('yournewpassword') WHERE AdminUserName = 'admin';

Troubleshooting

Common Problems & Fixes

❌

Blank white page / no styles loading

PHP errors are being suppressed. Check you imported both SQL files. Also open includes/config.php and verify DB_NAME is tms.

Check: http://localhost/tms/includes/config.php — should show blank page, not an error.
❌

Database connection error

Open includes/config.php and check DB_HOST, DB_USER, DB_PASS, DB_NAME. For XAMPP the defaults are correct. Make sure MySQL is running (green in XAMPP panel).

❌

Apache won't start (port 80 in use)

In XAMPP Control Panel → Apache → Config → httpd.conf → change Listen 80 to Listen 8080. Then access via http://localhost:8080/tms/.

❌

Images not showing / upload not working

On Linux/Mac, run the chmod 777 commands from Step 6. On Windows, right-click the uploads folder → Properties → Security → give full control.

❌

Admin login fails

Open phpMyAdmin → tms database → tbladmin table. Check the AdminUserName and reset password with this SQL:

UPDATE tbladmin SET AdminPassword = '' WHERE AdminUserName = 'admin';

Or just run it in phpMyAdmin SQL tab to set password to admin123.

Deployment

Uploading to a Live Web Server

1

Get Web Hosting

You need a hosting plan with PHP 7.4+ and MySQL. Recommended hosts: Hostinger, Namecheap, or InfinityFree (free option).

2

Upload Files via FTP or File Manager

Upload the entire tms folder to public_html/ on your server using FTP (FileZilla) or the hosting control panel file manager.

public_html/tms/
3

Create Database on Hosting

In cPanel → MySQL Databases → create a new database and user. Import database/legacy-sql/tms.sql then database/legacy-sql/v6_migration.sql via phpMyAdmin in cPanel.

4

Update Config

Edit tms/includes/config.php with your live hosting DB credentials (host, username, password, database name).
